Overview

What this API is for

This project is a backend-only REST API for managing a todo list. It exposes a handful of JSON endpoints that you can call from any HTTP client, script, or frontend.

Resource-oriented

Everything revolves around a single resource, /todos, using standard HTTP methods.

JSON in, JSON out

Send JSON request bodies where needed and receive JSON responses you can parse anywhere.

Flask + SQLite

Built with the Flask micro-framework and persisted in a lightweight SQLite database.

Endpoints

Available endpoints

Five endpoints cover the full lifecycle of a todo.

  • GET /todos Get all todos
  • GET /todos/<id> Get a single todo
  • POST /todos Create a todo
  • PUT /todos/<id> Mark a todo as completed
  • DELETE /todos/<id> Delete a todo

API reference

Requests & responses

Examples below use curl against a local server at http://localhost:5000. Adjust the host and port to match where you run the app. Response bodies are examples.

GET /todos Get all todos

Returns every todo as a JSON array.

GET /todos/<id> Get a single todo

Returns one todo, identified by its id. If no todo has that id, a JSON error is returned instead.

POST /todos Create a todo

Creates a new todo from a JSON request body. New todos start with the pending status.

PUT /todos/<id> Mark a todo as completed

Marks the todo with the given id as completed.

DELETE /todos/<id> Delete a todo

Deletes the todo with the given id.

Note: This page is a static API showcase. Use any HTTP client such as curl to call the endpoints above.
