# GitHub Profile Analyzer

A Python CLI tool that analyzes GitHub profiles using the GitHub REST API.

## Features

* View GitHub profile information
* List public repositories
* Show stars and forks
* Calculate total stars and forks
* Find the most-starred repository
* Find the most-used programming language

## Requirements

* Python 3.x
* `requests`

Install dependencies:

```bash
py -m pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

Enter a GitHub username when prompted.

## Tech Stack

* Python
* Requests
* GitHub REST API
