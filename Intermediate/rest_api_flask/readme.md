# REST API with Flask

A simple REST API built with Flask and SQLite for managing tasks.

This project demonstrates how REST APIs work and how clients can communicate with a backend using HTTP methods.

## Features

- Create tasks
- Get all tasks
- Get a task by ID
- Update tasks
- Delete tasks
- SQLite database for persistent storage
- JSON request and response handling
- Input validation
- API testing with Postman

## Technologies Used

- Python
- Flask
- SQLite
- Postman
