Features

Everything you need, nothing you don't

Built with Flask and SQLite — small enough to understand, solid enough to rely on.

⚡

Lightning fast

Lightweight Flask core with direct SQLite queries. No heavy layers between you and your data.

🛡️

Strict validation

Every request is checked for correct content type, valid JSON and non-empty fields before it touches the database.

🔁

Full CRUD

Create, read, update and delete notes with clean, predictable RESTful routes.

💬

Clear errors

Consistent JSON error responses with proper status codes — 400, 404, 405, 415 and 500.

🔒

Safe transactions

Every database call auto-commits on success and rolls back on failure, so your data stays consistent.

🧩

Easy to integrate

Works with any frontend, mobile app or script that can speak HTTP and JSON.

Reference

Simple, predictable endpoints

Five routes cover everything. Send JSON, get JSON back.

GET/notesList all notes200
GET/notes/<id>Fetch a single note by ID200 · 404
POST/notesCreate a note with title & content201 · 400
PUT/notes/<id>Update an existing note200 · 404
DELETE/notes/<id>Delete a note permanently200 · 404
